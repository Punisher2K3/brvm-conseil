# BRVM Conseil

Observatoire pédagogique indépendant à partir des sources officielles BRVM.

Édité par **Le Financier**. Nom public : **BRVM Conseil — par Le Financier**.

Voir [le fonctionnement autonome, les sauvegardes et les informations à compléter](EXPLOITATION.md).

Voir [la procédure de mise en ligne](GUIDE-GITHUB.md).

Voir [les cours rapides et le service prêt à héberger à la minute](COURS-RAPIDES.md). Le contrôle web à cinq minutes en journée complète la collecte horaire ; le service à 60 secondes attend un serveur permanent.

Le workflow collecte chaque heure, vérifie les calculs, construit `site-public` et déploie sur GitHub Pages. Aucun secret personnel requis. Les comptes annuels normalisés ne sont pas modifiés automatiquement.
